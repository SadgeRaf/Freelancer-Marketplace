# Freelancer Marketplace (Client)

A modern and responsive front-end application for a Freelance Marketplace platform. Users can browse jobs, view details, authenticate, and manage their own tasks with smooth animations and interactive UI.

---

## 🚀 Tech Stack
- **Frontend:** React, React Router  
- **Styling:** Tailwind CSS, DaisyUI  
- **Animations:** GSAP  
- **Authentication:** Firebase  
- **HTTP Client:** Axios  

---

## ✨ Main Features
- Secure sign-up/login via Firebase (Email/Google)  
- Browse, create, update, and delete jobs  
- Dynamic dashboard for authenticated users  
- Smooth animations and modern UI  
- Fully responsive for mobile & desktop
