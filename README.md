# Freelance Marketplace

A full-stack web application designed to connect freelancers and clients through a modern, responsive, and dynamic interface.

---

## 🚀 Tech Stack
- **Frontend:** React, React Router, Tailwind CSS, GSAP (for animations)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Firebase Authentication
- **HTTP Client:** Axios

---

## ✨ Features
- 🔐 **User Authentication:** Secure sign-up and login system using Firebase.
- 🧑‍💻 **Job Management:** Add, update, delete, and explore freelance jobs.
- 📂 **Dynamic Dashboard:** Authenticated users can manage their own jobs and tasks.
- 🎨 **Smooth Animations:** GSAP integrated for engaging motion effects.
- ⚡ **Full-Stack Integration:** Real-time communication between frontend and backend using RESTful APIs.
- 🧭 **Responsive Design:** Fully optimized for desktop and mobile devices.
